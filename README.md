# Snack & Dash v0.0.1.0

- **正式名称:** Snack & Dash
- **日本語名:** 食べ物集め鬼ごっこ
- **開発者:** Salt-Salt Games
- **リポジトリ:** https://github.com/saltsaltgames/snack-and-dash
- **配信:** Cloudflare Pages対応、HTML/CSS/JavaScriptのみの静的Webゲーム

## v0.0.1.0の変更内容

**操作系と画面レイアウトのみを拡張しました。ゲームのルール、速度、難易度、当たり判定、得点・記録方式はv0.0.0.6から変更していません。**

- スマホ・タブレットで遊べる固定式の仮想ジョイスティック
- 設定画面からジョイスティックと十字キーを切替可能
- 左右反転（左移動／右ダッシュ、右移動／左ダッシュ）
- 感度（デッドゾーン）5〜40%・表示自動/ON/OFF
- 左手で移動しながら右手でダッシュできるPointer Eventsの複数指対応
- `pointerup`、`pointercancel`、`lostpointercapture`、画面切替時の入力解除
- タッチ縦向きではゲーム画面の下、横向きではゲーム画面の左右に操作UIを配置
- Gamepad API：アナログスティック／十字キー、A・×・B相当ボタンでダッシュ、Start/Menu/Options/＋で一時停止
- コントローラー接続状態・切断時の一時停止、メニューのゲームパッド操作
- キーボード矢印/WASD、B/Space/Shift、Escape/P、Cキーの操作は維持
- 既存の`localStorage`保存キー・データ形式を変更せず、保存データを引き継ぎ
- **追加ライブラリ不要**。仮想ジョイスティックは軽量な標準Pointer Eventsで実装

## 操作方法

| 操作 | PCキーボード | タッチ | Gamepad API（標準マッピング） |
|---|---|---|---|
| 移動 | ←↑→↓ / WASD | ジョイスティックまたは十字キー | 左スティック / 十字キー |
| ダッシュ | B / Space / Shift | DASHボタン（複数指対応） | A/×/B相当（標準0・1） |
| 一時停止 | Esc / P | Ⅱ 一時停止 | Menu/Options/＋相当（標準9） |
| Collider表示 | C | ゲーム画面直下の切替スイッチ | キーボードかタッチで切替 |
| メニュー | クリック/タッチ | タップ | 十字キー/スティックで選択、決定ボタン |

Gamepad APIはOS・ブラウザ・機器に依存します。接続しても未検出の場合、ブラウザをアクティブにした後コントローラーのボタンを押してください。Gamepad APIはHTTPS（Cloudflare Pages）またはlocalhostでの使用を想定します。

## Debianで起動

ダウンロードZIPを展開して、`index.html`がある場所で次を実行します。

```bash
python3 -m http.server 8001 --bind 127.0.0.1
```

ブラウザで `http://127.0.0.1:8001/` を開きます。端末間でテストする場合は、ローカルPCに接続する代わりにCloudflare PagesのHTTPSデプロイを使用してください。

## Cloudflare Pagesにデプロイ

- Direct Upload: `Snack-and-Dash_Pages_v0.0.1.0.zip` をPagesにアップロード。ZIP直下に `index.html` と `_headers` を配置済み。
- Git連携: ZIPを解凍し、リポジトリのルートにコピーしてコミット・プッシュ。ビルドコマンドは**不要**、出力ディレクトリはプロジェクトルート。
- `_headers` はCloudflare Pagesによる配信時のみ適用（Python http.serverでは無視）。

## 保存データの互換性

保存キーは従来どおり `saltsalt_foodtag_v1`、保存スキーマは `version:2` です。過去の記録は同じオリジンなら引き継ぎます。URLのホスト名やポートが変わると別保存領域になるため、ゲーム内「記録」からJSONエクスポート/インポートで移動してください。
